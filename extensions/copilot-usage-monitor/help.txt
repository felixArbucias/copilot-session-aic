Copilot Usage Monitor - GitHub Copilot app plugin
Track AI credits used by each Copilot session, with live model and agent breakdowns.

Open: ask Copilot "Open Copilot Usage Monitor" in the session you want to measure.
The panel belongs to that conversation, even if several sessions are open.
It reads session.rpc.usage.getMetrics() every 3 seconds while visible.
Refresh and canvas refresh actions do not invoke an AI model.

Accounting:
- AIC = totalNanoAiu / 1,000,000,000 (the installed SDK's conversion).
- The main total is the runtime total, not a sum of model or agent rows.
- Work from subagents attributed to this runtime session is included.
  Separate child sessions have their own totals.
- Missing billing fields show Unavailable, not zero or premium requests.
- The runtime owns persistence/restoration. No local event tally is used.
  A restored session's breakdown can be less complete than its total.
- Totals update after usage is reported, not token-by-token during a call.
- These are reported session metrics, not an account-wide billing statement.

Privacy:
No external services, API tokens, dependencies, or AI calls are needed.
Only a loopback server is used, with a random per-panel URL and host checks.
No transcripts, repository files, or credentials are read.

Install through Customize > Plugins using the self-hosted marketplace:
felixArbucias/copilot-usage-monitor
Or: copilot plugin marketplace add felixArbucias/copilot-usage-monitor
    copilot plugin install copilot-usage-monitor@copilot-usage-monitor-marketplace
Existing sessions may need a restart or extension reload to discover it.
Close the panel to stop its server.
Uninstall: copilot plugin uninstall copilot-usage-monitor@copilot-usage-monitor-marketplace

Migrating from Session AIC v0.1.0:
Close the old panel. For the old marketplace installation, run:
    copilot plugin uninstall session-aic@session-aic-marketplace
    copilot plugin marketplace remove session-aic-marketplace
For the old direct installation, run: copilot plugin uninstall session-aic
CLI 1.0.86 cannot disable direct installs; uninstall the old copy instead.
Then use the new marketplace installation commands above.
GitHub URL redirects do not migrate plugin IDs automatically.
Disable or remove any personal user:session-aic extension before installing,
even if its display name is already Copilot Usage Monitor. That copy may keep
the legacy folder/canvas ID; different IDs still create confusing duplicate tools.
The packaged canvas ID is copilot-usage-monitor.

Tests: node --test usage.test.mjs server.test.mjs
The canvas APIs and usage RPC are experimental and may change with app updates.
